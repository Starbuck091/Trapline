# Trapline
_by Starbuck097_

Trapline is a mod for The Long Dark that completely changes the existing mechanics of using snares in the game towards greater realism. Thanks to this mod, snares will become another passive source of calories, just like tip-up fishing.

**Features:**

- Snares now work anywhere on the map, not just where rabbits live. 

- Now not only rabbits are trapped, but also ptarmigans.

- The loot in the snare depends on the arrangement. Each snare should be placed away from the other snare so that it works well, as well as keep a distance from buildings, campfires and sleeping areas.

- Each set snare makes a loot roll once a game day. The timer does not reset when saving and loading, time goes on even in those regions where the player is not currently present.

- Prey can "escape" from the snare by breaking it, or simply "bypass" it, as in real life.

- The more traps you set, the greater the chance to catch decent prey and not starve. 

- The mod does not depend on the spawn of animals, so if you are playing on hardcore builds where there are very few and almost no animals, this mod will be very useful.

- You can easily customize the mod for yourself using modSettings. The settings are localized in English and Russian.

**Dependencies:**

- ModSettings
